## 启动流程

需要启动两个服务。

### 1. 启动模型 API

运行 [start-qwen-api.ps1](F:/zz_codexs/记账笔记/start-qwen-api.ps1)：

```powershell
$env:API_HOST = "127.0.0.1"
$env:API_PORT = "8001"
$env:API_MODEL_NAME = "gpt-3.5-turbo"

conda run -n qwen_ft llamafactory-cli api F:\LLaMA-Factory\examples\inference\qwen3_bookkeeping_lora_sft.yaml
```

它会：

- 激活 `qwen_ft` 环境。
- 加载 Qwen 基础模型和 bookkeeping LoRA。
- 提供 OpenAI 风格接口：

```text
http://127.0.0.1:8001/v1/chat/completions
```

### 2. 启动记账服务

[package.json](F:/zz_codexs/记账笔记/package.json) 新增了：

```json
"start:qwen": "set OPENAI_BASE_URL=http://127.0.0.1:8001/v1&& set OPENAI_MODEL=gpt-3.5-turbo&& node server.js"
```

运行：

```powershell
npm run start:qwen
```

它会告诉记账后端：

- 模型 API 地址是 `http://127.0.0.1:8001/v1`
- 模型名称是 `gpt-3.5-turbo`
- 启动记账网页服务

## 文字解析过程

### 1. 页面发送文字

用户点击“解析到表单”后，[app.js](F:/zz_codexs/记账笔记/public/app.js:1124) 获取输入文字：

```javascript
const payload = await requestJson("/api/parse-entry", {
  method: "POST",
  body: JSON.stringify({ text }),
});
```

然后将后端返回的多条记录显示到表单：

```javascript
fillEntryForms(payload.records);
```

### 2. 记账后端接收请求

[server.js](F:/zz_codexs/记账笔记/server.js:594) 提供接口：

```text
POST /api/parse-entry
```

收到文字后调用：

```javascript
parseEntryWithModel(text)
```

### 3. 调用本地 Qwen

核心调用位于 [server.js](F:/zz_codexs/记账笔记/server.js:399)。

后端向 LLaMA-Factory 发送：

```javascript
fetch(`${LLM_BASE_URL}/chat/completions`, {
  method: "POST",
  body: JSON.stringify({
    model: LLM_MODEL,
    messages: [...]
  })
});
```

Qwen 返回类似：

```json
{
  "records": [
    {
      "t": "2026-06-01",
      "type": "自己支出",
      "name1": "食物支出",
      "name2": "甜点",
      "p": 32,
      "bak": "甜品"
    }
  ]
}
```

## 返回结果处理

模型结果不会直接写入账本，还会经过检查。

### 多笔记录处理

[server.js](F:/zz_codexs/记账笔记/server.js:307) 的 `splitLedgerText()` 可以识别：

- 一句话中的多笔消费
- 多个日期
- 普通数字金额
- 中文金额，例如“一千、两千、四百”

应用优先使用模型整段返回的多条结果。模型返回不完整或无效时，才逐笔调用模型补齐。

### 日期处理

支持将：

```text
26-06-01
```

转换为：

```text
2026-06-01
```

### 分类校验

模型返回的：

```text
type / name1 / name2
```

必须是表单类别列表中的有效组合。

例如：

```text
自己支出 / 食物支出 / 甜点
家里支出 / 食物支出 / 零食
```

如果组合无效，后端会尝试让模型修正或逐笔重新解析。

### 分类稳定规则

[server.js](F:/zz_codexs/记账笔记/server.js:19) 增加了别名和明确词语规则，例如：

```text
衣服 → 衣物
甜品 → 食物支出 / 甜点
手机 → 日用支出 / 电器电子
零食 → 食物支出 / 零食
```

这是为了处理训练数据冲突或模型偶尔返回同义词的问题。

## 多行表单功能

原来“新增账单”只能显示一条记录。

现在 [index.html](F:/zz_codexs/记账笔记/public/index.html:43) 改成动态多行表单：

```html
<form id="entryForm" class="entry-list"></form>
```

[app.js](F:/zz_codexs/记账笔记/public/app.js:172) 负责为每条记录生成一行：

```javascript
function entryRowHtml(record) {
  // 日期、分类、金额、备注、移除按钮
}
```

[app.js](F:/zz_codexs/记账笔记/public/app.js:195) 将模型返回的全部记录显示出来：

```javascript
function fillEntryForms(records) {
  // 渲染多行账单
}
```

用户可以：

- 修改每一条记录
- 移除错误记录
- 点击“全部保存到账表”

批量保存由 [app.js](F:/zz_codexs/记账笔记/public/app.js:1146) 调用：

```text
POST /api/records
```

后端在 [server.js](F:/zz_codexs/记账笔记/server.js:584) 将全部记录一次性写入 CSV。

## 主要新增内容总结

| 文件 | 主要功能 |
|---|---|
| `start-qwen-api.ps1` | 启动本地 Qwen LLaMA-Factory API |
